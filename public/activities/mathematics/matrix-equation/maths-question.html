教學例題 15.1 15A001

設 A 及 B 為下列矩陣。若 A = B，求 a、b、c 和 d。

A = 2a a + 2b b − c d + a = B = 6 5 7 −3
ready to begin step 0 of 6

solution steps

  1. 1
    compare positionsequal matrices have equal entries in the same position.
  2. 2
    find a2a = 6 → a = 3
  3. 3
    find ba + 2b = 5 → 3 + 2b = 5 → b = 1
  4. 4
    find cb − c = 7 → 1 − c = 7 → c = −6
  5. 5
    find dd + a = −3 → d + 3 = −3 → d = −6
  6. 6
    check the answersubstituting the values reproduces matrix B.

method: compare corresponding entries
