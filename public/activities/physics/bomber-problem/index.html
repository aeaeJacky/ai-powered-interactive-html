3The Key Idea: Two Independent Motions

A bomb released from a moving bomber does not fall straight down, and it does not fall behind the bomber either. Once released it keeps moving sideways exactly as fast as the bomber.

Independent motion #1 — horizontal (no force): air resistance is neglected, so there is no horizontal force on a bomb. Its horizontal velocity stays constant and equal to the bomber's velocity for the whole flight.
Independent motion #2 — vertical (gravity): the bomb starts with zero vertical velocity (dropped, not thrown) and accelerates downward with g, so its downward speed increases continuously.
x(t) = v t   and   y(t) = ½ g t²

The bomber itself also moves with x = v t. Because bomb and bomber share the same horizontal motion, at every instant each bomb is positioned directly below the bomber — no trailing, no leading. Meanwhile the vertical motion means the first-released (lowest) bomb is already moving fastest, so it pulls away — the gaps between successive bombs widen with time.

5Worked Solution (Step by Step)

Label the bombs by order of release. Let the interval be τ. If the instant shown is time T after the last bomb is released, then the bombs have been falling for times t₃ = T (last), t₂ = T + τ, and t₁ = T + 2τ (first).
Horizontal position — all bombs line up under the bomber. Each bomb keeps the bomber's horizontal speed v, so its horizontal displacement from the drop point is x = v t — identical to the bomber's own position x = v t. Therefore all three bombs are always directly below the bomber: the pattern is a vertical line.
Vertical position — drops grow. With zero initial vertical speed, each bomb falls a distance
y(t) = ½ g t²
The height differences between successive bombs (i.e. the visible gaps) are:
gap₂ = y(t₂) − y(t₃) = ½g[(T+τ)² − T²] = ½g(2Tτ + τ²)
gap₁ = y(t₁) − y(t₂) = ½g[(T+2τ)² − (T+τ)²] = ½g(2Tτ + 3τ²)
Since gap₁ − gap₂ = gτ² > 0, the gap between the two lowest bombs is larger than the gap between the two upper bombs.
In words: the lower a bomb is, the longer it has been accelerating, so the faster it is moving and the more it "pulls away" from the bomb above. The correct diagram therefore shows the bombs in a vertical line with gaps that increase going downwards.

Common misconception — why C is a trap

Many students think "the bombs are released at equal time intervals, so they are equally spaced." That is true for a train of objects moving at constant speed, but falling bombs are accelerating. Equal time intervals with increasing speed means the distances covered in each interval increase — so the separations grow.

6Quick Check — Can You Apply the Idea?

Q1 · A stunt car jumps horizontally off a cliff. While it is in the air, a passenger drops a coin out the window. Relative to the car, the coin
The coin keeps the car's horizontal velocity (no horizontal force), so it stays directly below the car — exactly like the bombs under the bomber. Answer: falls straight down below the car.
Q2 · Two balls are released one after another (1 s apart) from the same hovering drone. As both fall (no air resistance), the gap between them
The first ball started falling earlier, so it is moving faster; it pulls away. Gap increases (growing by gτ² every interval). Answer: increases.
Q3 · A package is dropped from a horizontally-moving helicopter (no air resistance). Just before it hits the ground, the helicopter is
Package and helicopter share the same horizontal velocity, so they travel the same horizontal distance — the helicopter is directly above the package on impact. Answer: directly above the package.
